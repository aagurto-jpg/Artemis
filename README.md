# AXIS-Z: Artemis (IB Biology) · private edition v5

Developed by Mr. A. Agurto, 2026 V1.0

Encrypted bilingual (EN/ES) SL/HL study app. Opens only with a personal access code.


## What's new in v6
- Diagram atlas (Practice → Diagram atlas): 17 diagrams (neuron, synapse, sarcomere, respiration pathway, chloroplast, membrane, heart, DNA replication, translation, prokaryote, alveolus, enzyme, leaf), including 4 simulated micrographs (animal cell, mitochondrion, chloroplast, root-tip mitosis).
- Label quiz in Paper 1A style: a red X marks a structure and the student picks its name.

## What's new in v5
- Save codes: students create a code (Settings or My progress) and paste it on any device to restore all progress.
- Heroes: 7 unlockable characters with powers (×2 XP, 50:50, second try, skip, ×3 XP, extra heart, reveal answer), refilled daily.
- Boss battles: 8 bosses (Rhinovirus → Pandemic X) with rising HP, timers and healing.
- Light theme by default, with a Light/Dark switch in Settings.

## Added in v4
- New name: AXIS-Z: Artemis (IB Biology).
- Calculation Gym: 23 stations (19 at SL) covering every calculation in the syllabus, each with a formula card, randomly generated problems, worked steps and star ratings.

## Added in v3
- 213 new original exam-style multiple-choice questions (418 in total), in English and Spanish.
- 26 new original Paper 1B / Paper 2 questions with markschemes (90 in total), including 6 extended-response questions.
- Optional breathing pauses: a 30-second guided pause from Home, offered after 10 questions or 3 misses in a row, before checkpoints and timed mocks, and after 15 minutes of study. Students can skip it, and it can be switched off in Settings.
- Checkpoint quiz: when a student finishes a set of flashcards, a short quiz on the same topics starts automatically, followed by an optional Paper 1B/2 question.

## How to update
Replace `index.html` and `app-part1.bin` in the repository with the files in this folder (keep `manager.html`).
Student codes created in the in-app Codes panel after the previous upload are not included in this `index.html`; create them again from the panel.
